# 项目文件地图 · 改什么去哪里

基于 `f47affd` 整理。行号会随改动漂移，函数名和注释关键词更可靠。

## 一分钟上手

| 目的 | 做法 |
|---|---|
| 打开项目 | 用 IDE 打开 `campus-mall/` 目录，或双击 `campus-mall.code-workspace` |
| 本地跑起来 | 双击根目录 `start-campus-mall.bat`（MySQL 3306 + 后端 3001 + 前端 8080） |
| 只改前端看效果 | 改完 `frontend/app.js` 直接刷新浏览器，免构建、无需重启 |
| 只改后端看效果 | 重启 `node backend/src/app.js` |
| 改完模板自检 | `node output/tpl-check.js`（脚本在工作区 output 下） |
| 部署到服务器 | `sudo bash deploy/scripts/update.sh`（必须在源码目录执行） |

## 前端（`frontend/app.js`，1802 行，单文件全部视图）

整个应用是一个 IIFE，根组件在文件末尾，各页面是独立的组件对象，靠 `views` 映射切换。

| 视图 | 起始行 | 负责内容 |
|---|---|---|
| `Login` | 269 | 登录 / 注册 / 管理员登录 |
| `Home` | 387 | 首页、分类筛选、搜索、猜你喜欢推荐位 |
| `ProductDetail` | 539 | 商品详情、加购、收藏、私信入口 |
| `Cart` | 616 | 购物车、结算下单 |
| `Orders` | 679 | 我买到的（待付款/已付款/已发货/已完成/已取消） |
| `SoldOrders` | 735 | 我卖出的、发货、确认 |
| `Publish` | 774 | 发布 / 编辑商品、图片上传 |
| `Messages` | 859 | 私信会话、AI 卖家「正在输入」 |
| `Profile` | 1005 | 个人资料、改密码、收货地址 |
| `Favorites` | 1100 | 我的收藏 |
| `Notice` | 1127 | 公告列表 |
| `Admin` | 1188 | 后台：统计、用户、商品、公告、交互分析、图表 |

路由与基础设施：

- `views` 映射表 —— 1734 行，新增页面要在这里登记
- `go(name, params)` —— 108 行，所有跳转入口
- `parseHash` / `hashchange` —— 123 / 144 行，hash 路由解析
- `userApi` / `adminApi` —— 30 行起，两套 axios 实例，各自带 token
- `U()` 请求封装 —— GET 的 `params` 必须走 `cfg.params`，否则参数静默丢失

入口与静态资源：

- `frontend/index.html` —— 引 `app.js?v=YYYYMMDDx`，**改完前端必须升这个版本号**
- `frontend/serve.cjs` —— 本地 8080 静态服务 + `/api`、`/uploads` 反代到 3001
- `frontend/vendor/` —— 内置 vue / element-plus / axios，不依赖 CDN

## 数据库（`backend/sql/`）

- `schema.sql` —— 13 张表的建表语句，**这是唯一事实来源**
- `migrate-*.js` —— 幂等迁移脚本，改表结构时新增一个（参考 `migrate-ai-seller.js`）
- `deploy/mysql/init.sql` —— 由 `schema.sql` 生成，**不要手改**

表：`user` `admin` `category` `product` `product_image` `address` `cart` `order` `order_item` `interaction` `message` `notice` `search_log`

## 演示版（`demo/`，与 `frontend/` 是两套代码）

- `demo/app.js` —— 演示版逻辑，结构同 `frontend/app.js` 但走浏览器内 mock
- `demo/mock.js` —— 假数据 + 假接口，含精简版 CF 引擎
- `demo/index.html` —— 入口

**改任何面向用户的功能，`frontend/` 和 `demo/` 两边都要改**，否则公网站点会落后。

## 常见修改场景速查

| 想做的事 | 去哪 |
|---|---|
| 改首页文案 / 布局 | `frontend/app.js` 的 `Home`（387 行） |
| 改推荐算法权重 | `backend/src/services/recommend.js`（浏览1/收藏3/加购4/购买5） |
| 改推荐理由文案 | `frontend/app.js` `Home` 里 `basis` / `reason` 渲染处 |
| 加一个新页面 | ① `frontend/app.js` 加组件 ② 1734 行 `views` 登记 ③ 顶栏加入口 ④ 同步 `demo/` |
| 加一个新接口 | ① `backend/src/routes/xxx.js` 写路由 ② `app.js` 34–44 行挂载 |
| 改订单状态流转 | `backend/src/routes/order.js`（5 态：0待付款/1已付款/2已发货/3已完成/4已取消） |
| 加敏感词 | 直接往 `backend/src/data/sensitive-words.txt` 加一行，重启生效 |
| 改 AI 卖家话术 | `backend/src/services/ai-seller.js` 规则段；或用环境变量切 LLM |
| 加一张表 | ① `schema.sql` ② 新增 `migrate-xxx.js` ③ 重新生成 `init.sql` |
| 改后台统计口径 | `backend/src/routes/admin.js`（`/stats`） |
| 改端口 | 后端 `PORT` 环境变量；前端 `frontend/serve.cjs` 顶部常量 |
| 改部署地址 / 域名 | `deploy/nginx/campus-mall.conf` + `deploy/env/api.env.example` |

## 改完务必检查

1. 模板引号闭合 —— 少一个引号整页白屏，`node --check` 查不出来
2. 前端升 `?v=` 版本号，否则浏览器吃旧缓存
3. `demo/` 是否同步
4. 改部署物料后跑 `python deploy/scripts/check-deploy.py`
5. 提交后推 `origin` 触发自动部署
